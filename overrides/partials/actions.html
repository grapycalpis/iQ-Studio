{#- Override of material/templates/partials/actions.html ────────────────────────────────────────────────────────────────── Purpose: rewrite the "Edit on GitHub" URL so symlink-based docs_dir doesn't leak the `src/` staging prefix into the URL. MkDocs resolves the edit_url from `repo_url + edit_uri + page src path`. When docs_dir is `src/` and `src/` is a symlink to `../`, the src path *as seen by mkdocs* may still be `src//...` in some configurations. Per ia-design.md §1 the authoritative GitHub paths are the real-source paths (no `src/`). This override strips a leading `/src/` segment from page.edit_url if it ever appears. If MkDocs already resolved the symlink, the replace is a no-op.
